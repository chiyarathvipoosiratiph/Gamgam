# ตารางติวหมอ 🩺💗

เว็บแอปติ๊กตารางอ่านหนังสือ (15-30 กันยายน 2569) ธีมสีชมพู-เขียว ใช้งานง่าย ไม่ต้องมี backend

## ฟีเจอร์ในแอป

- ติ๊กถูกรายคาบ + progress bar รวมทั้งเดือน
- ⏳ นับถอยหลังอัตโนมัติไปหาวันสอบจริงที่ใกล้ที่สุด (TGAT → TPAT → 9 วิชาสามัญ วันที่ 1/2)
- 🔥 นับวันต่อเนื่องที่อ่านครบทุกคาบ (streak)
- 📝 ช่องจดโน้ต/จุดที่ผิดในแต่ละวัน
- 📊 กรอกคะแนน Mock Exam แต่ละวิชาหลังสอบ แล้วดูกราฟพัฒนาการเทียบเส้นเป้าหมาย 80 คะแนน

## วิธีเอาขึ้น GitHub Pages (ฟรี)

1. สร้าง repository ใหม่บน GitHub เช่นชื่อ `study-tracker`
2. อัปโหลดไฟล์ทั้งหมดนี้เข้าไปใน repo พร้อมกัน (ต้องอยู่โฟลเดอร์เดียวกัน ไม่ต้องสร้างซับโฟลเดอร์):
   - `index.html`
   - `avatar.jpg`
   - `favicon.png`
   - `icon-180.png`, `icon-192.png`, `icon-512.png`
   - `manifest.json`
   - `README.md` (ไม่จำเป็นต้องอัปก็ได้ ไม่กระทบการทำงานของเว็บ)
   
   ลากไฟล์วางในหน้าเว็บ GitHub ได้เลย หรือ `git add . && git commit -m "add tracker" && git push`
3. ไปที่ **Settings → Pages**
4. ในหัวข้อ **Source** เลือก branch `main` และโฟลเดอร์ `/root` แล้วกด **Save**
5. รอ 1-2 นาที จะได้ลิงก์ประมาณ `https://<ชื่อผู้ใช้>.github.io/study-tracker/`
6. เปิดลิงก์นี้ในมือถือ แล้วกด **Add to Home Screen** เพื่อให้ใช้งานเหมือนแอปจริง

## หมายเหตุ

- ข้อมูลติ๊กถูกจะถูกเก็บไว้ใน `localStorage` ของเบราว์เซอร์เครื่องนั้นๆ (ไม่ sync ข้ามเครื่อง/เบราว์เซอร์)
- ถ้าอยากแก้ตารางเรียน (เพิ่มบทของวันที่ 21-30 หลังรู้ผล Mock Exam) ให้แก้ที่ตัวแปร `days` ในไฟล์ `index.html` ได้เลย โครงสร้างเป็น array ของแต่ละวัน แต่ละวันมี `sessions` 6 คาบ
- ปุ่ม "รีเซ็ตทั้งหมด" ด้านล่างสุดของหน้าใช้ลบข้อมูลติ๊กถูกทั้งหมด
